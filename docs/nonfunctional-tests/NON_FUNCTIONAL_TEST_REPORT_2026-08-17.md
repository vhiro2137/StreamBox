## 风险与限制

没有正式性能阈值，不能把建议基线当作验收标准。短时数据不能证明不存在内存泄漏。GPU数据为0且无法确认硬解路径；系统网络计数器不能归因到进程。独立首帧、跳转、切换和音画同步缺少可靠遥测。所有缺平台、设备、样本或系统变更条件的项目均按用户指示标记受阻并跳过，没有推断为通过。

## 最终判定

长稳和压力执行未发现崩溃、死锁、永久无响应或资源单向增长，但HTTPS证书真实性验证失败属于P0安全缺陷，因此总体判定“不通过”。可访问名称缺失为P1缺陷；2 Mbps/300 ms结果需复核。未实施任何修复。

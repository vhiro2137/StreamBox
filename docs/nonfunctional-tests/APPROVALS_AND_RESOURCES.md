# 待审批操作与资源清单

## A. 需要先确认的产品标准

- [ ] 支持的 Windows、Linux、macOS 版本和CPU架构。
- [ ] 基准硬件档位及4K/高码率/高帧率目标能力。
- [ ] 启动、加载、首帧、暂停、跳转和切换验收阈值。
- [ ] CPU/GPU/内存、线程、句柄、卡顿、丢帧和音画同步阈值。
- [ ] 长稳正式时长和允许资源净增长。
- [ ] 支持的URL协议、重定向、内网地址和错误提示策略。
- [ ] 目标可访问性规范与键盘操作要求。
- [ ] 用户数据在升级、降级和卸载时的保留策略。

## B. 需批准后才能执行的操作

| 操作 | 原因/风险 | 隔离与回滚 | 当前状态 |
|---|---|---|---|
| 运行长时/高负载测试 | 高资源、温度、长时间占用设备 | 专用测试机，温度/资源停止条件 | 未审批 |
| 网络限速、延迟、丢包和断网 | 改变网络状态，可能影响其他任务 | 隔离VM/代理，仅授权目标，结束后恢复 | 未审批 |
| 搭建TLS和重定向测试服务 | 涉及证书和网络策略 | 本机/隔离网，不导入系统信任或另行审批 | 未审批 |
| 安全异常样本测试 | 解析器风险 | 无网络隔离VM、快照、授权样本 | 未审批 |
| DPI、默认音频设备和多屏配置变更 | 改变用户系统状态 | 记录原值并恢复 | 未审批 |
| 安装/修复/升级/降级/卸载 | 改写系统文件、注册表和关联 | 快照VM；禁止在工作机直接执行 | 未审批 |
| 标准/管理员及多用户测试 | 权限和用户数据风险 | 临时隔离账号/VM | 未审批 |
| 安装或升级监控/网络工具 | 改变依赖和环境 | 优先使用已有工具；单独批准版本 | 未审批 |

## C. 所需外部资源

- 合法授权且有SHA-256的1080p、4K、高码率、50/60fps、长时和超大媒体。
- 带闪光/蜂鸣同步标记的标准音画同步样本及外部录制设备。
- Intel/AMD/NVIDIA硬件，多显示器和USB/HDMI/蓝牙声卡。
- Windows版本矩阵、Linux GUI/音频环境和macOS设备。
- 可回滚VM、授权HTTP/HTTPS测试服务器、隔离网络整形环境。
- 正式发行包、签名/清单、上一支持版本和安装说明。

## D. 可在较低风险审批后先执行的项目

1. 固定Windows环境的只读基线采样与关键时延测试。
2. 已有合法普通媒体的100次控制循环。
3. 30分钟长稳预检。

这些操作仍需明确允许“运行测试并生成证据文件”；如发现问题，只报告，不修改产品代码或实施修复。
